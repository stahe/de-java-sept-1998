## Einleitung

Dieses Dokument ist eine **Kursunterlage** und kein vollständiger Kurs.
Einige Themen erfordern die Anleitung eines Lehrers.

Dennoch finden die Studierenden hier eine Fülle von Informationen, die es ihnen in den meisten Fällen ermöglichen, selbstständig zu arbeiten.

---

## Empfohlene Literatur

Es gibt einige hervorragende Bücher über Java. Dazu gehören:

1. **Programming in Java**
   Claude Delannoy – Eyrolles

2. **Java Client-Server**
   Cédric Nicolas, Christophe Avare, Frédéric Najman – Eyrolles

Das erste Buch bietet eine hervorragende didaktische Einführung in die Programmiersprache Java.
Sobald man den Inhalt des ersten Buches beherrscht, ermöglicht das zweite Buch den Einstieg in fortgeschrittenere Themen:

* Java Beans
* JDBC
* CORBA / RMI

Es bietet zudem einen industriellen Blickwinkel auf Java.

Um Java in verschiedenen Bereichen zu vertiefen, ist die Reihe **„Java Series“** von O’Reilly eine nützliche Referenz.

Für den professionellen Einsatz von Java innerhalb einer J2EE-Plattform:

3. **J2EE Programming**
   Wrox Publishing (vertrieben von Eyrolles)

## Haftungsausschluss

Als dieser Kurs erstmals verfasst wurde (1998), beherrschte der Autor die Java-Codierungskonventionen noch nicht perfekt.

Zu dieser Zeit:

* Die Sprache steckte noch in den Kinderschuhen.
* Es wurde keine IDE verwendet, um Verstöße gegen die Namenskonventionen zu melden.

Folglich:

* Die Namen von Klassen und Schnittstellen sollten mit einem Großbuchstaben beginnen.
* Diese Regel wird im Dokument nicht konsequent befolgt.

Außerdem sind viele der vorgestellten Technologien mittlerweile veraltet:

* RMI
* CORBA
* Swing
* Applet
* Die IDE JBuilder

Anstatt dieses Dokument neu zu schreiben, wurde 2015 ein neuer Kurs erstellt:

👉 **Einführung in die Programmiersprache Java und das Spring-Ökosystem anhand einer Fallstudie (2015)**:  
[https://stahe.github.io/de-java-spring-dec-2015/](https://stahe.github.io/de-java-spring-dec-2015/)

Dieser neue Kurs basiert teilweise auf einigen Kapiteln des vorliegenden Dokuments.

Es wird empfohlen, den Kurs von 2015 als Hauptquelle zu nutzen und das vorliegende Dokument nur dann zu konsultieren, wenn darauf verwiesen wird.
